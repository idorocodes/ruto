## Brand & Style

The design system is tuned for dynamic, student-led campus mobility under real-world transit conditions. Designed primarily for mobile-first, one-handed navigation between lectures, bus stops, and hostels, the system balances utility with approachable, tech-forward confidence. 

The aesthetic is a high-contrast dark mode tailored for direct sunlight legibility as well as night commutes. It combines structural discipline with tactile friendliness: deep obsidian foundations, high-visibility kinetic green accents, and large, reliable hit targets. The visual style avoids excessive ornamentation in favor of crisp boundaries, subtle tonal shifts, and clear typography, ensuring information can be parsed at a glance while in motion.

## Colors

The palette establishes immediate functional hierarchy through deliberate contrast:

- **Primary Canvas (`#11161C`)**: Deep, low-fatigue slate black setting a grounded foundation across the viewport.
- **Surfaces & Cards (`#1A222B`)**: Elevated dark navy-charcoal used for all interactive containers, bottom sheets, and route cards.
- **Structural Borders (`#2A3541`)**: A neutral, 1px low-contrast outline ensuring clear component separation on dark panels without harsh visual noise.
- **Accent Green (`#3DDC97`)**: High-luminance mint/emerald signaling paths, active ride statuses, CTAs, and verification indicators.
- **Primary Content (`#F6F4EE`)**: Warm off-white to eliminate high-contrast glare while maintaining maximum readability.
- **Muted Content (`#B9C2CC`)**: Balanced cool silver-grey reserved for route metadata, secondary details, and non-active states.
- **Status Alert (`#FF5A5F`)**: Crisp coral-red for route cancellations, emergency markers, and critical input validation.

## Typography

The typography implements a three-tier system calibrated for legibility, interface guidance, and verification:

1. **Space Grotesk (Display & Headings)**: Provides a sharp, tech-forward feel to wayfinding titles, campus node points, and header banners. Its geometric shapes maintain an energetic student-focused identity.
2. **Inter (Body & Controls)**: Delivers neutral, universally accessible legibility across route directions, user ratings, and general UI copy under variable outdoor lighting conditions.
3. **JetBrains Mono (Codes, Hashes & Metadata)**: Purpose-built for security codes, driver plate tags, vehicle verification pins, ETA counters, and data-dense route identifiers to prevent character confusion (e.g., distinguishing `0` and `O`).

## Layout & Spacing

The layout is built on an 8pt baseline grid emphasizing bottom-weighted interaction areas for effortless single-hand mobile operation:

- **Mobile Viewports (<768px)**: Uses a 4-column fluid layout with a mandatory `16px` outer margin. Interactive elements (booking actions, search inputs, active filters) stay pinned within the thumb zone via sticky bottom sheets and floating action modules.
- **Tablet / Desktop (≥768px)**: Transitions to a centered 8-to-12 column structured grid with a maximum content canvas of `1024px` to keep routes and tracking feeds readable rather than overly stretched.
- **Touch Targets**: All primary interactive buttons, toggle selectors, and sheet triggers maintain a strict minimum height of `48px` (ideally `56px`) with at least `8px` separating touch boundaries to prevent accidental triggers while walking.

## Elevation & Depth

Visual hierarchy uses tonal surface stepping, fine border delineations, and targeted focus glows rather than muddy drop shadows:

- **Base Layer (`#11161C`)**: Canvas backdrop holding base maps and structural view layouts.
- **Surface Elevation (`#1A222B`)**: Applied to cards, bottom sheets, modals, and navigation bars. Each elevated layer is bound by a crisp `1px solid #2A3541` border to delineate separation against the base layer.
- **Interactive Layer**: Hovered, tapped, or active components advance via an interior fill shift (e.g., to `#222C37`) alongside an accent border brightening.
- **Accent Glow**: Reserved for active live status items (e.g., active GPS path, vehicle arriving). Created using an ambient radial blur (`0 0 16px rgba(61, 220, 151, 0.25)`) directly behind the element rather than standard dark drop shadows.

## Shapes

The interface implements a cohesive curvature language designed to feel approachable and tactile:

- **Containers & Surfaces**: Cards, bottom sheets, input fields, and modal containers use a unified radius of `16px` (`rounded-lg` level 2), creating friendly yet solid containers.
- **Bottom Sheet Edge Cases**: Pull-up sheets feature `16px` rounding exclusively on top-left and top-right corners, sitting flush against the screen baseline.
- **Small Controls & Chips**: Tag chips, pills, and system badges scale down to `8px` or take fully circular pill forms (`9999px`) to contrast cleanly against rectangular cards.
- **Pill Targets**: Interactive bottom primary action buttons adopt a rounded pill or matching `16px` curvature for consistent visual weight.

## Components

- **Buttons**:
  - *Primary*: Background `#3DDC97`, text `#11161C` (Space Grotesk, bold), 56px height on mobile. Radius `16px`. Active state subtly dims to `#34BE82`.
  - *Secondary*: Surface `#1A222B`, border `1px solid #2A3541`, text `#F6F4EE`. Focus/hover highlights border to `#3DDC97`.
  - *Destructive*: Surface `#1A222B`, border `1px solid #FF5A5F`, text `#FF5A5F`.

- **Cards & Route Panels**:
  - Background `#1A222B`, border `1px solid #2A3541`, radius `16px`, padding `16px`. Internal divider lines use `#2A3541`. Route paths highlight start and destination points using green and white accent nodes.

- **Inputs & Search Bars**:
  - Background `#1A222B`, border `1px solid #2A3541`, radius `16px`, height `52px`, text `#F6F4EE`, placeholder `#B9C2CC`. Focused state transitions border to `#3DDC97` with a subtle outline rings (`0 0 0 2px rgba(61, 220, 151, 0.2)`).

- **Route Chips & Transit Tags**:
  - Height `32px`, border-radius `9999px`, padding `0 12px`.
  - Active: Background `rgba(61, 220, 151, 0.15)`, text `#3DDC97`, border `1px solid #3DDC97`.
  - Inactive: Background `#1A222B`, text `#B9C2CC`, border `1px solid #2A3541`.

- **Verification Code Blocks**:
  - High-visibility display for booking and driver codes using JetBrains Mono (`label-code`). Enclosed inside a bordered `#11161C` container with 2px letter tracking for glanceable pickup validation.

- **Checkboxes & Selection Toggles**:
  - Base square `20px` with `6px` radius, border `1px solid #2A3541`. Checked state fills `#3DDC97` with an `#11161C` tick checkmark.

- **'Powered by Gemma' Attribution Badge**:
  - Sleek, compact badge positioned unobtrusively in route-finding footers or drawer headers. 
  - Styled with a subtle semi-translucent container: background `rgba(26, 34, 43, 0.7)`, border `1px solid rgba(42, 53, 65, 0.8)`, border-radius `9999px`, padding `4px 10px`. 
  - Uses `JetBrains Mono` (`badge-mono`) at `11px`, pairing an accent-tinted spark/dot in `#3DDC97` with muted text `#B9C2CC` for a clean, non-intrusive finish.
